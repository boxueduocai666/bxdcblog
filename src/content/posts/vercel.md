记录一下将静态博客托管到 Vercel 和 GitHub Pages 的过程。

从最开始只有一个 HTML 文件，到后来加入液态玻璃视觉、响应式布局和文章管理，这个博客也慢慢变成了一个真正属于自己的小站。

## 两种托管方式

GitHub Pages 与 Vercel 都可以托管静态生成的网站。选择时应考虑部署流程、自定义域名、构建日志、国内访问线路和项目维护习惯。
