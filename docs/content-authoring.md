# Content Authoring

Posts live in `src/content/posts/*.md`. Required frontmatter: `title`, `date` (`YYYY-MM-DD`) and `category`. Optional: `tags`, `excerpt`, `draft`, `pinned`, `cover`.

Use ordinary Markdown headings. Headings from h2 to h4 are included in the generated article table of contents. Use fenced code blocks for examples; the reader enhancement adds a copy button without changing the code HTML source.

Draft posts are excluded from all public lists and generated routes.
